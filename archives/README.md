# archives 研究过程档案 — 说明

> 给**人**看的说明（程序不读取本目录，只写入）。

## 是什么

每次研究任务完成时自动封存的过程档案，命名：`生成时间_主题.md`。内容：

- 元信息（引擎 / 模式 / 流程 / 任务等级 / 价值观框架）
- 执行计划（两引擎均记录）
- 各角色中间产出（调研素材 / 批判性审阅 / 科学分析 / 人文视角 / 人工补充等，缺失跳过）
- 事实审核结果（如有）+ 最终文章全文

## 用途

- 研究过程追溯 / 复盘 / 复用（是任务历史回放的地基）
- 资源浏览器 → 日志功能分区可直接浏览

## 注意

- 程序自动生成，**建议只读**；要整理请复制后操作
- 已 gitignore，不入版本库
- 每次研究 = output/（成稿）+ archives/（过程）配套
