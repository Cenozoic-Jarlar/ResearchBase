# output 输出目录 — 说明

> 给**人**看的说明（程序不读取本目录，只写入）。

## 是什么

研究文章输出目录。任务完成时程序写入，命名：`生成时间_主题.md`
（如 `20260911_2013_各种外星人和人类的思维底层差异和对行为模式的影响.md`）。

## 人工可以做什么

- 查看 / 复制 / 分享文章
- 转 Word：`venv\Scripts\python.exe md2docx.py`（缺省转换本目录全部 md；也可指定文件/目录）
- 需要长期保存的成品，建议移动/复制到自己的文档目录管理

## 注意

- 程序不读取本目录，人工改动无程序风险
- 重跑同主题会生成新文件（时间戳不同），不会覆盖旧文件
- 每次研究的完整过程（含各角色产出）在 `archives/`，成稿在 `output/`，两者配套
