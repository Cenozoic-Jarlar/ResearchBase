# memories 长期记忆池 — 人工维护说明

> 给**人**看的说明（程序不读取本文件）。任务启动时由记忆顾问自动读取固定文件并注入。

## 是什么

跨任务记忆：记录用户长期偏好，任务启动时自动注入价值观体系（value_profiles）。

## 文件

| 文件 | 作用 | 谁维护 |
|---|---|---|
| `user_prefs.md` | 用户长期偏好，任务启动自动注入 | 人工（优先）/ AI |
| `task_history.md` | 任务历史沉淀占位（后续版本自动写入） | 程序（未来） |
| `README.md` | 本说明 | 人工 |

## 怎么改 user_prefs.md

直接编辑（文本编辑器，或资源浏览器 → 档案管理 → memory/memories/）。格式：每行一条或一个分组。

```
- 输出语言：中文
- 表达偏好：精炼、避免空话
- 研究习惯：结论优先，附数据来源
```

- 程序只读取固定文件名（`user_prefs.md`），**其他文件不会被注入**，可放心放说明/草稿
- 修改后**新任务**生效，无需重启服务

## 注意

- 偏好越具体，任务启动时对角色行为的约束越明确
- 不想让某条偏好生效，删除该行或注释即可（`#` 开头行会原样注入，建议直接删除）
