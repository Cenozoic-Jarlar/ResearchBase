# LocalDataBase 本地资料库 — 人工维护说明

> 这是给**人**看的说明（程序不读取本文件）。主题库被研究员（researcher）按需读取，
> 命名与索引规范直接影响程序检索质量。

## 这个文件夹是什么

程序的主题化资料库。**每个子目录 = 一个主题库**，主题库 = 含 `_repo.md` 索引文件的子目录。

```
LocalDataBase/
├─ README.md            ← 本说明文件
├─ 00-测试资料/          ← 主题库示例
│  ├─ _repo.md          ← 仓库索引（程序自动维护，人工也可改）
│  ├─ 01-旧归档示例.txt  ← 资料文件，命名：编号-主题短语
│  └─ 02-示例资料.txt
└─ 01-新主题/            ← 新建主题库的格式（NN-主题短语）
```

## 怎么新建 / 修改

1. **新建主题库**：建子目录 `LocalDataBase/NN-主题短语`（如 `01-新能源政策`），
   放入资料文件，文件命名 `NN-主题短语.txt / .md`（编号保证排序，中英文均可，人工/AI 都易读）
2. **`_repo.md` 索引**：含主题库自描述 + 每个文件的一句话摘要。用程序入口写入会自动生成；
   人工手建时参照 `00-测试资料/_repo.md` 的格式
3. **程序入口（推荐）**：
   - 资料采集流程（material_import）/ 采集员：URL / 本地文件 / 文本 → 自动整理入库（自动编号 + 摘要索引）
   - 写入 Skill：`write_local_database(filename, content, topic, ...)`（自动建库/编号/更新 _repo.md）
   - 资源浏览器 → 档案管理分区：可直接查看/编辑资料文件和 _repo.md（保存前自动备份 .bak）

## 程序读取策略（了解即可）

- 三级读取：概览（_repo.md）→ 主题摘要 → 按需全文；短文件（≤2000 字符）摘要时自动附全文
- 一次只读一个主题库，不全部拼接（省 token）

## 注意事项

- 文件命名保持 `编号-主题短语` 风格，编号保证排序
- **改资料文件后，_repo.md 的摘要索引可能过期**：手动更新，或等程序下次写入该库时刷新
- 删除主题库 = 直接删子目录；删除前确认不再需要
