# 模板域：目录骨架说明

本目录（`_模板域/`，下划线开头 = **隐藏**，不会被注册为真实域、不出现在 GUI 域列表）
是新建域的模板。复制本目录、改名（去掉下划线）即为新域，例如 `domains/工作A/`。

```
domains/<你的域名>/
├─ _domain.md          # 域配置（可空；"默认价值观"填框架名，任务在该域自动采用）
├─ LocalDataBase/      # 域内主题资料库（与根 LocalDataBase/ 同构，按主题子目录存放）
├─ output/             # 域内研究输出（文章）
└─ archives/           # 域内研究过程档案
```

- **注册规则**：`domains/` 下任何非 `_` 开头的子目录 = 一个域（自动注册，无需改代码）。
- **读取**：任务选定域后，资料读取顺序 = 域内 → 通用层（根 LocalDataBase/）。
- **写入**：默认进当前域；想写通用层，创建任务时域留空（通用层）。
- **命令**：GUI 任务表单可新建/切换/重命名域；CLI 运行 `main.py` 时按提示输入域。
