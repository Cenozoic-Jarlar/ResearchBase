# 主题域（domains/）说明

## 这是什么
本目录用于**按主题隔离**人工可维护的资料内容。每个子目录 = 一个"主题域"（隔离单元），
域内通常包含：

```
domains/<域名称>/
├─ LocalDataBase/   域内主题资料库（与根 LocalDataBase/ 同构，按主题子目录存放）
├─ output/          域内研究输出（文章）
└─ archives/        域内研究过程档案
```

## 与根目录（通用层）的分工
- **根目录** `LocalDataBase/`、`output/`、`archives/` = **通用层**（跨域共享，默认写入目标）。
- **域目录** = 域私有。任务创建时选定域后，资料读取顺序为"**域内 → 通用**"，写入默认进当前域。
- 想写通用层：创建任务时选择"通用层"，或在域参数留空。

## 怎么用
1. 在 GUI 任务表单"主题域"下拉选择或新建域；命令行运行 `main.py` 时按提示输入域（回车=通用层）。
2. 不同主题（如"工作项目 A" / "个人研究 B"）分开放不同域，互不干扰；
   需要复用的通用资料放根 `LocalDataBase/`（跨域共享）。
3. 本目录内容（除本说明文件）默认不入 git 版本库，属个人知识资产；
   如需纳入版本控制，修改项目根 `.gitignore` 相应规则。

## 域内结构与命名规范（与通用层一致）
- 主题库目录：`NN-主题短语`（中英文均可，编号保证排序）。
- 资料文件：`NN-主题短语.md`（编号自动补全）。
- 输出/档案文件：`生成时间_主题短语.md`（程序自动命名）。
